# Engineering lessons

- Source construction timestamps, analysis time and current wall time are separate concepts. Declare the method clock and finite context applicability explicitly; do not infer them from a freeze date or hidden schedule.
- A bounded configuration snapshot and a final source-generation comparison prevent a convenience CLI path from bypassing the normal integrity boundary. Persist effective settings so verification does not depend on a mutable configuration filename.
- Strict models do not make copied or manually constructed objects trustworthy. Revalidate snapshot counters/types, immutable inventories and observed sizes at the scoring boundary; reject boolean counts and contradictory completeness metadata.
- Keep source-cohort counts, alert counts and reference-episode supports distinct. Expected misses remain positives. False-positive alerts are not the numerator of benign-episode contamination.
- Reuse canonical statistics and preserve their null semantics. F1's positive support differs from its ratio denominator; label both meanings and retain multiplicity when a whole family is sampled more than once.
- Exact schema bytes and runtime agreement establish structural conformance, not source ownership, semantic truth, independent evaluation or quality. Retain explicit unrun, inapplicable, incomplete and zero-support states.
- A moved source closure needs its license, schema assets, test-package imports and path mapping as well as Python modules. Preserve upstream bytes and failures; change only the declared consumer namespace/paths.
- Keep original required evidence references and rejection denominators authoritative. Register them before producing citations; an escaped parser-valid physical row can exceed the canonical Pointer cap and must remain an unresolved original requirement. Never truncate, fabricate a successful empty result or silently replace an unsupported citation.
- Unit/component counts and nested relocation controls overlap. Report actual command scope, candidate and retained execution timings; do not add overlapping totals or manually guess durations.
- A relocated source tree and an editable environment do not prove package installation. Validate a built wheel in a fresh environment, check actual import origins and required vendor assets, and explicitly exclude reference-data construction code from distributable packages.
- Measure numeric text in a real narrow viewport. Allowing every table cell to break anywhere can split values and units into misleading fragments; keep statistics values/units together and scroll the table within the page.
- Keep the useful local workflow small. Self-contained artifacts need no forced cloud, UI server or database. Explicit portability and deferred-feature notes are more reliable than claiming unprovisioned readiness.

- Preserve a failed native runner attempt as an evidence limit. Passing source, escaping and installed-wheel checks cannot supply missing viewport, scroll or keyboard observations. Package the actual current renderer and keep earlier accepted wheels tied to their original bytes.
