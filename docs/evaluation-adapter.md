# Public method configuration and private matching

`config/evaluation-public-setup.v1.json` is a new, explicitly named evaluation configuration. The ordinary `config/rules.json` baseline remains unchanged with empty allowlists. Earlier reports do not acquire this configuration retroactively. Source setup is synthetic, with documentation address ranges and agent-authored reference labels; none establishes human verification or model quality.

Load the profile explicitly with `PublicEvaluationProfile.model_validate_json`, then parse an explicitly supplied source using its `internal_cidrs`. `public_settings(parsed, profile)` validates a complete snapshot and that its recorded directions agree with those CIDRs. It supplies the existing detector with the public permitted destinations/services and scanner, backup and health contexts. It performs no file access or method invocation. The controller must pin original profile bytes as well as the returned canonical typed-content digest: these are different hashes.

The analysis clock is the maximum observed source-event timestamp. Context start is the minimum observed timestamp; end and expiry are maximum plus one microsecond, with no recurring schedule. These are newly declared method semantics for the observation interval. The original synthetic construction clock and static context declarations did not specify a method clock or activation intervals. Current UTC, freeze time and execution duration have no role. A maximum timestamp at the signed 64-bit endpoint is refused because the context endpoint cannot be represented; it is never clamped. Empty complete sources have clock zero, zero observed rows and no instantiated contexts.

Scanner suppression applies only to the declared scanner source, public internal destinations, TCP/UDP and scan/sweep rules. Backup and health use their exact declared source, destination, protocol, service and rule. The existing detector still requires every supporting row to match a context before suppression. Suppressions remain in its audit groups. The finite interval is not a recovered private schedule, and no expected-miss positive or difficult benign reference is removed.

## Pure matching boundary

`domain.evaluation.matching.score_rules` accepts one trusted parsed source, an actual `RuleRun`, an explicit tuple of `GoldEpisodeV1` reference objects and a declared pattern subset. The five primary patterns are the default; `rejected_then_established` is evaluated separately by explicit selection. It remains a Zeek connection-state diagnostic with no firewall deny/allow inference. `score_proxy` accepts the two actual app proxy-run types and enforces their declared narrow applicability. Proxies retain their distinct public-design mechanics and omit contexts; they are not executions of the referenced third-party products.

The boundary verifies complete source counters and generation, unique physical rows, known source membership, matching support digests, closed ordered subject parts and strict primitive types, support timestamps inside each half-open window, exact run config, unique group/episode identities, complete requested channels and fixed limits. Partial, capped, quarantined, excluded, capture-loss or incomplete units are refused. A caller must still establish source currentness before and after execution, authentic reference provenance and actual method execution. Consistent digest strings and typed objects are not authenticity proofs. No source path, split, constructor, dataset or corpus loader is consulted here.

An eligibility edge requires the same pattern, directional subject key and intersecting half-open time window. Integer row overlap is compared against the **episode's** full support: one half is primary; one quarter and three quarters are fixed sensitivity checks. Complete supports count, rather than selected examples or a prediction-based denominator. Maximum total overlap assignment is one-to-one, then maximizes cardinality, then stable edge rank and ordered Hungarian ties. Stable item order is window start/end followed by full identity. Bit masks encode membership in the validated source inventory; their intersections preserve exact integer counts without constructing a large set for every pair.

Matched positive pairs are TP; unmatched flagged predictions are false-positive alerts; unmatched positive or expected-miss episodes are FN. Suppressed groups are audit-only. All applicable benign episodes remain in a separate denominator. Every benign episode touched by any eligible flagged prediction counts once, independently of positive credit. Thus one alert can affect several benign episodes, several alerts affecting one benign episode count once, and an alert can earn positive credit while also contaminating benign support. False-positive alert counts and affected-benign counts cannot be substituted for each other.

The result is scorer-private raw counts, edges and identities. It contains no measured true-negative population, rates, intervals, accuracy or model-quality verdict. Empty support produces explicit raw zero counts, never a perfect metric. The existing assignment limits are 256 selected predictions/episodes and 65,536 possible edges per relation; limits refuse rather than sample. All original source groups are bounded at 10,000 and source rows at 250,000. Out-of-scope groups are recorded separately, not assigned phantom metrics.

## Remaining integration

Canonical S2 evalkit supplies the actual generic models, rate/classification helpers, manifest admission and whole-family bootstrap. The separately implemented [S8 canonical components](canonical-evaluation.md) now provide a concrete DomainAdapter, registered local-source methods, closed public aggregates and count/report callbacks with new hand-toy conformance. The original private source-family corpus conversion and independently admitted experiment remain pending. No current corpus quality, floor attainment, heldout experiment or annotation accuracy follows from public hand controls. Rules-plus-annotation methods must preserve exact rules-only detection; annotation outcomes are a separate evaluation axis. Unrun methods stay unmeasured.

The D8 implementation lineage remains excluded from actual S8 corpus/Gold execution, heldout tuning, adjudication, independent finished-app review and acceptance. An independently assigned controller must pin the complete source/config/runtime/adapter/scorer/method/split/Gold/seal closure before any permitted experiment. Frozen artifacts remain immutable, and a source-blinding failure is not repaired by passing checks or changing labels.
