# Source-backed evidence/proposal controls

Hand-written pytest inputs exercise own EvidenceRef resolution against original
synthetic source bytes. The generic checker recomputes all declared statistics and
each claim's declared support, unit and formatting before fixed-template rendering.
Examples are optional display references and cannot replace aggregate evidence.
Empty/model-only explanations cannot pass. Changed, absent or foreign source data
fails closed. The domain adapter independently reloads WP02 source and derives the
actual WP04 catalogue for its declared config/context/analysis clock.

Neutral text begins `NOT APPLIED — proposal for human review`. It keeps directional
endpoint/protocol/source-port associations, compresses only adjacent observed
destination ports, and does not expand IPs into networks or produce device commands.
Suppressed, partial, unclear or explanation-failed groups yield investigation text.

No S5 Pointer/dispatch contract or code has been supplied. These are explicitly own
EvidenceRef/domain staging adapters, not a canonical foreign wire/schema or vendoring
claim. No independent Gold, scoring, provider, report or full workflow is established.
